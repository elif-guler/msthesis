#+TITLE: 6-Strain E. coli Marker & Sequence Analysis Pipeline

* Overview
This directory contains the automated pipeline and evaluation scripts comparing diagnostic marker identification tools (*Fur* and *SeqWin*) across 6 distinct /E. coli/ clades (*A*, *B1*, *B2*, *D*, *E*, and *F*). It also includes downstream analysis to assess whether clade-unique markers preferentially associate with Mobile Genetic Elements (MGEs).

* Directory Structure
- *a, b1, b2, d, e, f/* :: Subdirectories containing clade-specific target/neighbor symlinks, local phylogeny (~eco33.nwk~), downloaded reference genomes, and output databases.
- *pipeline.sh* :: Main pipeline automation script for dataset preparation, symlinking, and running *Fur* across all clades.
- *run_fur_seqwin.sh* :: Execution wrapper for running SeqWin alongside Fur.
- *run_cons.sh* & *analyze_cons.py* :: Scripts to calculate conservation, divergence, and off-target hit statistics.
- *blast_markers.py*, *blast_markers_reverse.py* & *extract_unique.py* :: Scripts to perform reciprocal BLAST checks between Fur and SeqWin markers and extract tool-unique sequences.
- *venn_prep.sh* :: Prepares unique marker FASTAs (~fur_unique.fasta~ and ~seqwin_unique.fasta~) for each clade and summarizes overlaps.
- *gin_mge_test.sh* :: Maps unique markers to reference coordinates, counts observed MGE overlaps, and performs a 10,000-iteration Monte Carlo permutation test.
- *calculate_marker_bp.sh* :: Summarizes marker counts and total sequence lengths (base pairs).
- *plot_*.R* :: R visualization scripts for generating summary grids, histograms, and MGE permutation null distributions.

* Execution Workflow

** 1. Run Main Pipeline
Construct target/neighbor sets and execute initial Fur database creation across all 6 clades:
#+begin_src bash
  bash pipeline.sh
#+end_src

** 2. Marker Analysis & Sequence Comparison
Run sequence conservation analysis, evaluate marker overlap between tools, and measure total marker base pairs:
#+begin_src bash
  bash run_cons.sh
  bash markers.blast.sh
  bash calculate_marker_bp.sh
  bash venn_prep.sh
#+end_src

** 3. Mobile Genetic Element (MGE) Permutation Testing
Fetch reference genomes and test whether clade-unique FUR markers are significantly enriched within annotated MGEs:
#+begin_src bash
  # Run MGE permutation tests across clades with unique markers (B2, D, E, F)
  for c in b2 d e f; do
      bash gin_mge_test.sh "$c" fur_markers
  done
#+end_src

** 4. Visualization
Generate summary plots, comparative grids, and permutation null distribution histograms:
#+begin_src bash
  Rscript plot_grid.R                 # Fraction of neighbors hit vs Divergence
  Rscript plot_condiv.R               # Conservation vs Divergence grid
  Rscript plot_marker.R               # Marker base pair comparison histogram
  Rscript plot_fur_in_seqwin.R        # Fur markers coverage vs identity in SeqWin
  Rscript plot_null_grid.R            # MGE permutation null distribution histograms across clades
#+end_src
